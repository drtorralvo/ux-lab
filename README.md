# UX Lab

UX Lab es un proyecto donde reúno herramientas que me hacen más fácil el trabajo como product y UX designer. Cada una resuelve una tarea concreta del día a día y queda empaquetada para reutilizarla en cualquier proyecto. Por ahora arranca con dos, y se irá actualizando con más skills.

Cada herramienta está construida como una *skill* para Claude: un archivo con el método, los criterios y el código que ejecuta, todo a la vista.

## Cómo trabajan

- Señalan y explican, pero la decisión es de quien diseña.
- Separan lo que resuelve la máquina (cálculos, mediciones) de lo que es criterio humano.
- Verifican antes de afirmar: ningún resultado se da por cierto sin confirmarlo.
- Son honestas con lo que está mal, sin maquillar.

## Herramientas

### Auditoría de accesibilidad
Revisa la accesibilidad de una página o de un sitio según WCAG, en seis frentes: textos alternativos, contraste, jerarquía de encabezados, navegación por teclado, etiquetas de formularios y uso del color. Cada hallazgo incluye su evidencia, un recorte visual de dónde ocurre y una sugerencia concreta de mejora.

### Sistema de diseño
Construye un sistema de diseño desde cero o audita uno existente, guiando con preguntas. Deriva las escalas (color, tipografía, espaciado, tokens) a partir de pocas decisiones base, integra accesibilidad en cada dimensión y exporta un paquete listo para usar (tokens en JSON, CSS y componentes).
